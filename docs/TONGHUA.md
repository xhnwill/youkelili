# 《童话》简谱转尤克里里四线谱

版本 0.4.0 · 2026-10-26。依据用户在聊天中上传的谱图人工转录，未调用外部 AI。

## 使用

打开 https://youkelili.xiao-dev.top/#example=tonghua 或点击工作台“载入《童话》四线谱”。无需配置 AI。可以试听、校对、保存工程；勾选校对后可导出。打印请优先使用独立的 5 页 PDF，避免浏览器对整幅长 SVG 的分页差异。

- PDF：/examples/tonghua.pdf，5 页，每页标明演奏小节和原谱小节。
- 工程：/examples/tonghua.jianpuuke.json，在网页版“打开工程”中载入；带原图、音符和校对说明，不含接口或密钥。
- 其他：/examples/tonghua.svg、tonghua.mid、tonghua.musicxml。

## 音乐设置

1=Gb（降 G），4/4，四分音符=78。标准 High G：G4-C4-E4-A4；四线从上到下 A/E/C/G。保留原调与原八度，音域 Db4-Bb5，实际品位 0-13，控件最高允许15品。

本示例为完整单旋律，未补写伴奏和弦。65 小节，440 个音符／休止事件，260 拍，标准速度约 3 分20秒；同音持续段连接30处。每小节均为4拍，没有超出音域的音。

## 反复路线

原图只有一房／二房和反复终止线，未明确标出回跳起点。用户明确选择按歌曲衔接：“你哭着”后回到“对我说”段。

演奏路线：原谱 1-30 → 13-27 → 31-50，共65小节。第28-30小节为一房，第31小节起为二房。工程 sourceBarMap 和 PDF 标签记录每个演奏小节对应的原谱位置，避免把展开后的序号误当成原谱小节号。

## 延音与校对

- 输入 ~ 连接相同音高，例如 `5/4 ~ | 5 -`；保留两个小节的音符片段，但实际持续发声、不重新拨弦。
- TAB 中括号品位为前音的延续，指法保持相同弦位。试听／MIDI 合并持续音，MusicXML 保留延音起止。
- 异音弧线只按原有音高、时值转录，未自行增加击弦、勾弦、滑音技巧。
- 原谱第18小节末尾 `2 1` 未见高音点，依图转为中音；与其他版本或演唱习惯可能不同，明确标记为重点复核。
- 最后小节的延长记号按基本4拍导出；实际演奏可自由延长，不把自由延长虚构成固定时值。

## 重建

    node website/scripts/build-tonghua-example.mjs <临时score.json路径>
    python website/scripts/render-tonghua-pdf.py <临时score.json路径> website/public/examples/tonghua.pdf

PDF 使用 ReportLab 与中文 TrueType 字体。所有音高与指法来自同一份网页音乐核心，PDF 脚本不另行计算指法。28 项网页测试含延音合法性、MIDI 单次触发、MusicXML 与降 G 调、示例的全小节节奏／路线／可弹音域检查。
