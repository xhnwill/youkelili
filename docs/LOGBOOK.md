## 2026-10-26 · v0.3.1 · AI JSON 与 Kimi K3 兼容修复

### 原因与决定

- 用户遇到“AI 未返回约定的 JSON”。旧实现将截断、无最终答案和格式差异合并报错，无法据此确认此次实际上游响应；不把接口错误直接认定为模型不支持图片。
- 网页请求增加 JSON 模式；Kimi K3 改用 max_completion_tokens 32768、reasoning_effort low，保留思考，上游／浏览器超时调整为 180／200 秒。
- 只有明确拒绝 response_format 的 HTTP 400/422 才回退一次；不对已生成结果自动重试，不持久保存图片、密钥或上游回复。
- 解析最终答案的文本块、围栏、闭合 think 标签和外部说明；禁止使用 reasoning_content、修补残缺 JSON 或导入被截断结果。
- 错误分为回复截断、仅思考、拒绝、字段缺失、非 JSON 和音符格式错误。升级版本 0.3.1，构建日期 2026-10-26；Windows 便携成品仍为 0.1.0。

### 验证

- 新增 8 项回归测试：Kimi 参数、回复变体、截断、仅思考与拒绝、错误结构、受限回退及错误分类；25 项 Node 测试通过。
- 12 项 Python 回归、生产构建和 Wrangler dry-run 通过。
- 已部署 Cloudflare，版本 ID 64be6ed3-a06a-4249-b4b4-c71e2cfe8325。公网版本接口确认 0.3.1，app.js 已含新超时和等待提示，非法识谱地址返回 HTTP 400。
- 没有读取用户凭据或真实 AI 回复，仍需用户刷新后以自己的谱图与接口复测；此次真实故障属于哪类上游响应尚不能确定。
