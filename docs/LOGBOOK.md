# 项目日志

## 2026-10-26 · v0.1.0

### 需求与决定

- 用户要求“简谱图片 → 尤克里里四线弹奏谱”的开源软件。
- 用户确认：只用联网 AI，不安装本地 OCR；仓库为 github.com/xhnwill/youkelili。
- 先创建本地 Git，核对远端无已有分支后按新项目准备。
- 采用 MIT 许可、Windows 本机浏览器 GUI、Python 标准库服务。范围先锁定单旋律，不自动补写伴奏。

### 实现

- 图片导入、方向规范化、框选裁剪，兼容视觉模型接口设置和转录提示词。
- 识别结果可校对；支持音阶、升降、高低八度、减时、附点、延音、休止和小节线。
- High G / Low G、调号、移八度、最高品位设置，动态规划指法，超出音域明确标出。
- 简谱对照四线 SVG、合成试听、MIDI、MusicXML、打印 PDF、工程保存和恢复。
- 密钥仅在页面内存，工程和日志不含接口凭据。
- Windows 单文件打包脚本、自动测试与 GitHub CI。
- 最终成品使用 Python 3.12.14；打包时保留托管运行时附带的 SSL 证书资源，修复仅在 exe 中触发的接口请求缺文件错误，不改变证书校验方式。

### 验证

验证结果与局限统一记录在 VALIDATION.md。外部 AI 实测需要用户配置自己的服务，不将模拟响应当作真实识谱成功。
