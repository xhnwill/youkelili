# 文档目录

- AI_INTERFACE.md：接口配置、请求协议、隐私与实测边界。
- ARCHITECTURE.md：数据流、音乐语义、指法算法和关键取舍。

- VALIDATION.md：测试结果、打包与真实识谱验证状态。
- THIRD_PARTY.md：依赖和分发许可证。
- preview.png：工作台与四线谱的实际截图（如已生成）。
- WEB_DEPLOYMENT.md：网页版的数据流、Cloudflare 目标、部署步骤与公网验证记录。
- TONGHUA.md：用户上传《童话》的完整四线谱示例、反复路线、导出和校对边界。
- CATALOG.md：简谱之家目录、搜索、预览和选页导入的行为与来源边界。
- catalog-preview.png：v0.3.0 在线找谱本地浏览器验证截图。
