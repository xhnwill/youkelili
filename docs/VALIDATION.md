# v0.1.0 验证记录

日期：2026-10-26。环境：Windows x64；源码回归使用 Python 3.9.1，最终 Windows 打包使用 Python 3.12.14；Pillow 11.3.0；PyInstaller 6.16.0。

## 已验证

- Python 编译检查、前端 JavaScript 语法检查。
- 12 项 unittest 回归：全部支持调号与 High G / Low G 的弦位音高匹配、明确的音域错误、不静默移八度、严格语法、节奏分数、小节校验、SVG 转义、MusicXML 音高拼写和技术指法、MIDI 短附点精度。
- 模拟视觉服务器的图片 Base64 / Bearer / 模型字段、识别 JSON 到四线谱及三种导出链路；HTTP 401、非 JSON、错误 JSON 形状与重定向拒绝；无密钥回显。
- 本机 HTTP 服务的会话 token 校验、静态页面及非法输入报错。
- 实际浏览器界面：加载《小星星》示例后显示 42 个音符／休止；简谱与四线谱对齐，核对状态和导出按钮生效；试听按钮进入播放状态。这里验证了播放器状态，未记录外部设备实听。
- 实际浏览器界面：输入低八度 5，在 High G 下提示超出音域，导出不会将其伪装为可弹音。
- Windows 单文件 exe 已构建，并通过本机 HTTP 版本查询及打包后的图片解码、模拟视觉接口、8 音符转换、SVG/MIDI/MusicXML 导出冒烟验证。
- 成品实际界面：配置本机模拟视觉接口、点击“AI 识别简谱”，成功回填 4 个音符与校对提示并生成四线谱。这是接口与 UI 链路测试，模拟服务没有识图能力。

## 尚未验证

- **真实联网 AI 识谱**：未配置用户自己的视觉模型地址和密钥，未提交用户谱图；不能据此宣称识谱准确率或服务商已接受请求。
- 真实尤克里里演奏可弹性、人工音乐审校。
- 其他 Windows 机器上的干净系统运行；源码支持其他平台，但本次未做平台测试。
- 长篇、多页复杂谱的打印分页。
- GitHub CI 运行结果以远端 Actions 为准，本地通过不等于远端已通过。

## 验收建议

从清晰的 4–8 小节单旋律简谱开始。配置真实视觉接口后逐音检查 1=、上下点、减时线、附点和延音；选择与琴一致的定弦；先试听再演奏。复杂谱分行识别，保留每段校对记录。
